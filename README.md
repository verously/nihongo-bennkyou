# ことばスタジオ (Kotoba Studio) — 日本語スピーキング練習コーチ

写真や統計グラフを見て自分で考え、30〜60秒の日本語スピーチを録音・添削できるデスクトップ向け Web アプリです。  
JLPT N3 程度の学習者が無理なく日常的にスピーキング練習できる **ステップガイド（N3）** と、中上級向けの **フリースピーチ** の2モードに対応しています。

## 主な機能

- **ステップガイド（N3 向け）**：写真・グラフに対して「1. 見えること → 2. 感想・経験 → 3. 自分の意見」の3つの質問に声またはテキストで短くメモしながら考えを整理し、最後に自分のメモを見ながら 30〜60 秒のまとまったスピーチを話せます（話す前に模範解答・意見の例は一切表示しません）。
- **フリースピーチ（中上級向け）**：ガイドなしで写真・統計グラフを見てすぐ 30〜60 秒スピーチに挑戦できます。
- **音声録音・再生 & 30〜60秒ペースタイマー**：`MediaRecorder` による実音声録音・波形表示・聞き直し再生・`Space` キーでの録音開始／停止・Chrome/Edge でのリアルタイム文字起こしに対応。
- **Gemini API 連携（音声直接理解・Web検索グラウンディング）**：
  - 録音した音声そのものを Gemini に送り、**4つの観点（内容の構成・文法・語彙・自然な表現）**から「良かった点」と「改善すべき点」を具体的にフィードバック（発言の丸ごと書き換えは行いません）。
  - Web検索で統計グラフ用データを取得・発言中の事実確認（事実と意見の区別）を実施。
  - APIキー未設定でも、内蔵の厳選お題（写真4種＋統計グラフ2種）とデモコーチで全フローを体験できます。
- **2回目リトライ & 成長比較**：1回目の改善ポイント（2〜3個）だけを左側にピン留めし、同じテーマで2回目に挑戦して変化を比較できます。
- **全日文 UI ＋ ふりがな ON/OFF**：画面全体と AI フィードバックの漢字ふりがなをワンクリックで切り替え可能。使えるフレーズの日本語発音読み上げ（TTS）にも対応。

## ローカル起動方法

```bash
npm install
npm run dev
```

起動後、右上の **「API設定」** から [Google AI Studio](https://aistudio.google.com/apikey) で取得した Gemini API キーを登録すると、音声の直接解析・Web事実確認・お題自動生成が有効になります（キーはお使いのブラウザの `localStorage` のみに保存されます）。
